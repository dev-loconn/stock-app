# 用带源时间的逐笔行情确认美股扩展时段报价

基础报价中的 preMarket 和 afterMarket 价格缺少各自时间戳，不能证明属于当前交易日和当前时段。美股进入盘前或盘后时，额外订阅 ETH 逐笔并拉取近期成交，以源时间、OpenD 市场状态和服务器日期确认报价，再按已确认的收盘基准计算涨跌幅；数据或基准不完整时明确等待或显示未知。

这一选择接受额外逐笔订阅额度和请求成本，以保留报价时段与时间的可核验性。常规时段继续使用基础报价；不支持夜盘，不直接将无时间的扩展字段当作当前有效报价。固定样本及 SDK 协议夹具已验证逻辑，真实盘前盘后仍待验收。

2026-11-01 追加：0.8.0 应用户要求扩展支持美股夜盘，原“不支持夜盘”的范围限制由 [夜盘规则与验证](../overnight-validation.md) 替代。继续要求独立源时间，并将跨美东午夜的成交视为同一轮夜盘，按该轮开始前最近的常规收盘基准计算涨跌。
