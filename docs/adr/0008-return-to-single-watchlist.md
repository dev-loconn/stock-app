# 恢复单一自选列表，按总清单迁移旧分组配置

用户在使用 0.10.1 后明确要求移除不实用的分组功能，0.11.0 因此移除切组按钮、分组管理、成员关系和分组命令接口，恢复单一自选列表及每只证券的展示勾选。旧 v4 配置按“全部自选”的完整排序和勾选迁移为 v5，不以最后活动分组筛选总清单，也不合并各组的展示开关，避免遗漏其他组的证券或将原先隐藏的证券自动展示；原 v4 文件在迁移前独立备份，以保留被撤销的组内选择。此决定替代 [ADR 0007](./0007-overlapping-watchlist-groups.md)，验证见[移除分组记录](../remove-watchlist-groups-validation.md)。
