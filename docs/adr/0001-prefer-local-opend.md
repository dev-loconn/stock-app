# 第一版优先通过本机 OpenD 接入行情

个人自用的 Windows 11 行情悬浮条优先验证并采用本机 OpenD 的接入路径，登录和验证码由富途官方程序处理，悬浮条不保存富途密码。本机已有运行中的 OpenD，因而选择复用该路径，接受额外网关进程；直接连接富途云端的免网关 REST/WebSocket 暂不作为第一版主路径。

此决定于 Q17 获用户确认。Q23 用户选定 Electron 后，接入验证转向 JavaScript SDK 和 OpenD 的本机 WebSocket 接口，区别于直接连接富途云端的免网关通道。Electron 兼容性、实际连接配置、账号行情权限及盘前盘后收盘基准仍须验证。方向确认不等于接入验证通过；若验证无法满足已确认需求，需记录证据并重新讨论替代方案。
