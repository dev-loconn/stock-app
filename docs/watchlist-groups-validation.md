# 自选分组验证（0.10.0）

历史记录：0.11.0 已按用户要求移除此功能，当前行为见[移除分组记录](./remove-watchlist-groups-validation.md)。

2026-11-01，按已确认的[自选分组设计](./watchlist-groups-design.md)实现。开发和测试使用 Node 24.22.1、Electron 45.0.0；原生检查使用隔离配置和本机行情协议夹具，不读取或修改日常实例的配置和凭证。

## 实现范围

- 一份总自选清单、固定全部自选视图及可交叉归属的手动单层分组；各视图独立维护成员顺序和悬浮条展示勾选。
- 设置页提供创建、改名、确认删除、分组拖拽排序、已有自选批量加入、组内移出及总清单确认移除。搜索添加绑定发起时的目标视图；已有自选可离线加入。
- 悬浮条通过原生组名菜单切换，长名省略、菜单保留全名；控件宽度与字号计入窗口及分页计算。面板跟随当前视图，保持展开和焦点意图，显示组名与成员总数。
- 配置 v1/v2/v3 迁入 v4，保留顺序、明确空选择、位置、外观、连接与受保护密钥、快捷键。损坏或未来版本文件禁止静默覆盖；仅活动组缺失时恢复全部自选并提示。
- 主进程串行处理候选配置，写盘成功后提交并广播。保存失败保留已提交状态；所有视图共享行情身份，切组和本地成员编辑不主动重连或增加订阅。

## 验证边界

全屏检查向既有可见性控制器注入全屏样本，验证真实窗口保持隐藏及恢复；未将其描述为独占游戏或物理多屏的完整验证。当前桌面的不同字号已覆盖，其他实际 DPI、极窄工作区和物理多屏仍需人工环境检查。原生菜单的鼠标操作可在使用时核对；自动化覆盖组名按钮存在、受控切组入口和完整切组结果。

行情为合成协议夹具，不代表新增实盘权限验证；分组不扩大行情源权限、额度或市场覆盖。首轮沙盒测试的临时文件重命名和回环连接被系统拒绝，后在允许这些本地操作的环境中通过；未为绕过测试更改产品的保存或连接策略。
