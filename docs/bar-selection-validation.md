# 悬浮条展示选择与每页数量验证（0.7.0）

日期：2026-10-25（Asia/Shanghai）。完整方案已获用户最终确认并实施。对应 [设计规则 Q1–Q12](./design.md) 与 [验收清单 J 组](./acceptance.md)。

## 实现范围

- 自选管理每行增加“显示在悬浮条”复选框，保存成功后生效；自选总数和勾选数分别显示，列表内部滚动，保留拖拽排序。
- 外观增加“悬浮条每页最多显示”，默认 3，接受可精确表示的正整数，不设置任意股票数量上限。实际每页容量同时受工作区及单只证券宽度约束。
- 仅勾选项进入横条分页，滚轮翻页和末页留空保留。展示选择、排序或每页数量变化回到第一页，普通报价更新保持当前页。选择变更后再恢复原选择也不会恢复旧页码。
- 新增和移除后重新添加默认不展示；配置 v1/v2 迁移到 v3 时缺失的选择默认展示，默认每页 3。明确保存的全部取消选择在重载后保持为空；原位置、连接、外观和受保护密钥继续保留。
- 移除应用自选的加载、添加、替换列表校验及界面中的 10 只限制。诊断工具自身的 1–10 只输入范围不属于应用自选，本次不调整。
- 展示选择不改变行情订阅范围，不触发重建连接。云端连接或请求失败时，受影响行标记异常，保留全部自选及展示选择。
- 外观写入失败会恢复上次成功的外观配置；开机自启写入与失败恢复继续使用原生接口，系统拒绝恢复时明确提示。
