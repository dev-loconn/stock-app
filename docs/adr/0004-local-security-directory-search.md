# 证券搜索采用可持久化的本地证券目录

为满足断线搜索、停止输入约 200 毫秒后更新候选结果及后台刷新的已确认需求，证券搜索采用可持久化的本地目录；目录超过一天时在连接可用后后台刷新，刷新失败仍保留已有可用目录。富途虽然提供[在线标的搜索](https://openapi.futunn.com/futu-api-doc/quote/get-search-quote.html)，但逐次在线请求受连接与调用频率约束，因此本地目录承担输入联想，目录数据来源和补充名称覆盖率另行核查。

此决定于证券搜索访谈 Q5、Q8、Q10 获用户确认，并在整体方案最终确认后于 0.4.0 实现；只持久化证券搜索资料，行情报价仍沿用原有的不跨启动缓存规则。实际名称覆盖边界及证据见 [名称资料](../security-name-sources.md) 与 [搜索验证](../security-search-validation.md)。
