# Windows 11 股票行情悬浮条

已实现显示真实富途行情的 Electron + React + TypeScript + Vite 悬浮条。0.7.0 支持在自选管理中勾选悬浮条展示证券、自定义每页数量，并取消应用内自选总数上限。全部自选行情在依附横条的面板中展示。搜索使用本地目录，已有目录可断线搜索；行情源覆盖及权限以对应验证记录为准。此前版本的恢复验收记录继续保留。

0.5.0 默认使用富途云端网页登录授权，无需 OpenD；保留本地 OpenD 作为手动选择的备用连接。接入行为、验证及限制见 [云端桌面集成](docs/cloud-desktop-validation.md)。

0.6.0 将独立的全部自选行情窗口替换为依附横条的紧凑面板：点击右侧箭头展开，最多显示 6 行，其余内部滚动；点击外部或按 Esc 收起。实现、原生交互验证和待验边界见 [面板验证](docs/watchlist-panel-validation.md)。

0.7.2 修复美股盘前盘后报价与涨跌幅：云端补拉带源时间的逐笔，并订阅扩展时段成交；休市重启恢复最近盘后行情。SOXL 的真实数据核对及未验范围见 [修复验证](docs/us-session-validation.md)。

0.8.0 支持美股夜盘行情：按实际成交时段取价，跨美东午夜保留同一轮夜盘基准，默认云端和本地 OpenD 备用均已接入。真实 SOXL 夜盘响应、自动验证和待实盘范围见 [夜盘验证](docs/overnight-validation.md)。

0.9.0 增加全局快捷键：显示／隐藏横条、展开／收起面板及前后翻页，支持录入改键、单项禁用、整组保存和冲突重试。快捷键展开不抢焦点，长按只执行一次，全屏期间不操作。默认组合及完整规则见[快捷键设计](docs/global-shortcuts-design.md)，实际验证和默认键占用情况见[验证记录](docs/global-shortcuts-validation.md)。

0.9.1 将本机冲突的三个默认快捷键改为 Ctrl+Alt+Q（面板）、Ctrl+Alt+J/K（前后翻页），保留 Ctrl+Alt+H（显隐）。三组替代键已在本机实测可注册；旧版默认项随升级替换，自定义和禁用项保留。见[默认键修订验证](docs/default-shortcuts-0.9.1-validation.md)。

0.10.0 增加自选分组：同一证券可加入多个手动分组，各组独立保存排序与展示勾选；横条组名菜单切组，面板和设置同步。保留“全部自选”，旧配置自动迁移，支持离线管理已有证券。规则与验证见[分组设计](docs/watchlist-groups-design.md)和[验证记录](docs/watchlist-groups-validation.md)。

0.10.1 缩窄分组按钮：默认字号从 80 减至 44 个逻辑像素，两字组名完整显示，“全部自选”按钮简写为“全部”；长名保留省略与完整菜单。见[紧凑按钮验证](docs/compact-group-selector-validation.md)。

0.11.0 按用户要求移除分组，恢复单一自选列表并释放按钮空间。旧分组版配置会先备份，再按“全部自选”的完整顺序和勾选迁移，保留全部证券及其他设置。见[移除分组记录](docs/remove-watchlist-groups-validation.md)。

0.11.1 取消单只证券宽度 140～360 的限制，接受正整数；窗口仍按屏幕空间适配，字号和透明度保留原范围。见[宽度验证记录](docs/unrestricted-security-width-validation.md)。

0.11.2 修复盘前涨跌基准被 QUOTE 推送覆盖，以及较旧的常规报价时间阻止新夜盘价格更新的问题；各时段独立比较源时间，保留已确认基准。真实盘前推送核对及夜盘回归范围见[行情修复验证](docs/quote-session-fix-0.11.2-validation.md)。

0.11.3 将悬浮条和自选行情面板的价格改为最多三位小数，例如 81.1258 显示为 81.126；涨跌幅继续保留两位小数，行情原始精度及计算不变。

0.11.4 将行情价格统一为固定两位小数；美股杠杆／反向 ETF 在悬浮条显示纯代码，通过名称特征和代码名单识别，覆盖 SOXL、SOXS、TQQQ。面板和设置保留名称。规则、范围及验证结果见[显示设计](docs/etf-ticker-display-design.md)。

0.12.3 增加港美股市场筛选、可自定义的切换市场快捷键和自选列表“移到最前”；精简悬浮条并支持整条拖动，修复 Windows 非整数显示缩放下拖动尺寸累积和面板对齐误差。

便携使用：完整解压 release/stock-bar-0.12.3-win32-x64.zip 后，双击 stock-bar.exe；无需 Node.js 或 npm。在设置中点击“登录富途”，通过系统浏览器授权后自动连接。详情见 [便携使用说明](docs/portable-guide.txt)。

## 运行

开发需要 Windows 11 x64、Node.js 22.12 以上。默认云端模式无需 OpenD；使用备用模式时才需要单独启动并登录 OpenD。

```powershell
npm ci
npm run setup:electron
npm run build
npm start
```

首次启动会显示空自选悬浮条及设置窗口，默认选择富途云端。点击“登录富途”，在官方页面仅授权行情读取；刷新凭证由 Windows 系统保护加密保存，下次启动自动连接。访问令牌不返回到页面、不写入日志；退出云端登录清除本机保存的凭证。

升级已有配置时默认选择云端，保留旧自选、外观、位置及本地密钥；手动选择备用模式后会保存该选择。在“本地 OpenD（备用）”中配置 WebSocket 端口、SSL 和密钥，点击“应用并连接”。默认 33333，TCP 的 11111 不用于此连接。切换会停止旧连接并清空旧来源报价。

开发版已接入 AKShare 港股、美股和沪深京 A 股名称库。输入名称、代码片段或拼音首字母（如腾讯、Tencent、700、tx、gzmt），点击结果旁“添加”，由富途云端按完整代码核验身份、品种后订阅行情。应用不限制自选总数，支持 A 股筛选、键盘选择、删除和拖动排序；目录有记录不代表账号具备行情权限。

目录同步需要 Python 3.10+ 和 AKShare（行情显示本身无需 Python）。首次配置及主动同步：

```powershell
npm run setup:akshare
npm run sync:securities
# 只重试美股，其他市场缓存保持可用：
npm run sync:securities -- --market=US
# Python 不在 PATH 时：
powershell.exe -NoProfile -File scripts/setup-akshare.ps1 -Python 'C:\path\to\python.exe'
```

程序启动后在后台检查目录，超过一天自动同步；“刷新目录”无需登录富途。各市场失败时保留旧目录，支持离线搜索；首次美股同步可能需要数分钟。开发版和同步命令共用 `.cache/security-directory-akshare.json`；以后打包版本保存到用户数据目录的 `security-directory-akshare.json`，不覆盖旧 OpenD 目录。可用 `STOCK_BAR_PYTHON` 指定已装 AKShare 的 Python 解释器，发布脚本包含同步脚本但不捆绑 Python。0.6.0 便携包包含这项当前源码能力；原有 0.5.0 ZIP 不包含。

名称和别名覆盖因数据源而异，不承诺全市场双语或所有俗称。A 股名单含沪深京，但 A 股 ETF 名单未额外导入；已知 ETF 完整代码仍可核验添加。港股及美股来源可能含其他证券类型，添加前统一由富途过滤为股票/ETF。来源及映射见 [名称资料](docs/security-name-sources.md)。

云端未返回某只证券报价时，会尝试该证券的官方快照并标注“快照”；仍无数据时逐只提示，不影响其他证券。当前账号港美报价已实测，沪深京样例可核验身份但报价/快照均未返回，不能把目录覆盖理解为行情权限已开通。真实同步和验证记录见 [AKShare 验收](docs/akshare-directory-validation.md)。

当前机器的 npm 不在 PATH，可使用已准备的本地 npm（开发 Node 使用兼容版本）：

```powershell
node .cache/npm-cli/package/bin/npm-cli.js run build
node .cache/npm-cli/package/bin/npm-cli.js start
```

setup:electron 安装锁定版本的 Electron 并校验 SHA-256。如 GitHub 下载不可达，可配置 Electron 支持的 ELECTRON_MIRROR 镜像并保留校验。

## 使用

- 默认全局快捷键：Ctrl+Alt+H 显示／隐藏横条，Ctrl+Alt+Q 展开／收起面板，Ctrl+Alt+J/K 前后翻页。设置页“全局快捷键”可直接录入组合、禁用、恢复默认；点击“保存快捷键”整组生效。组合被其他软件占用时会逐项提示，释放冲突后可“重新尝试”，也可改键。
- 自定义至少包含 Ctrl、Alt、Shift 中两个修饰键，主键支持字母、数字、方向键、F1–F11；Win 组合、单键和系统保留的 F12 不支持。录入时暂停快捷键操作，Esc 或切换窗口取消录入。长按仅执行一次，修饰键保持按住时可松开主键再按。
- 快捷键显示横条或展开面板不抢当前应用焦点；面板主要使用同一组合收起，Esc 仅在面板自己有焦点时有效。全屏自动隐藏期间四项操作不执行；手动隐藏后面板组合会恢复并展开，翻页组合不执行。
- 空白手柄拖动；鼠标滚轮手动翻页。外观设置可修改“悬浮条每页最多显示”，默认 3，接受正整数，窄屏自动减少实际数量。
- 自选管理每行勾选“显示在悬浮条”后即时保存，展示顺序跟随拖拽排序；修改选择、顺序或每页数量后回到第一页。新增证券默认不勾选，旧配置已有自选保留展示，重启记住选择。
- 自选不设应用内固定数量上限；管理列表内部滚动，显示总数及展示数。未勾选项仍更新行情并出现在全部自选行情面板，全部取消时横条提示选择展示证券；行情服务受限时保留自选并显示异常状态。
- 单只证券宽度默认 180 逻辑像素，接受正整数；调字号保持宽度，末页不足时留空。宽度大于屏幕可用空间时按工作区收窄。旧版总宽设置自动迁移为单只 180，其余配置保留。
- 正常连接只显示小圆点；断线或重连仅在左侧显示一次简短提示，悬停查看连接详情。
- 点击右侧小箭头展开全部自选行情面板，再次点击或在面板获得焦点时按 Esc 收起；点击外部保持展开。右键、托盘及设置的“查看行情”也打开同一面板。每行展示名称、代码、价格、涨跌幅及状态；最多 6 行，更多内容内部滚动，通过“管理自选”进入设置。
- 面板随横条移动，默认贴在下方，空间不足时向上展开或缩小；隐藏及全屏时一起收起，恢复和重启后保持收起。手动隐藏后查看全部行情会恢复横条；全屏隐藏期间则提示退出全屏后再查看。
- 横条和面板不弹出行情悬浮详情；源时间及报价时段仍保留在内部行情模型中。
- 点击齿轮或右键菜单打开设置；右键菜单可重新连接、隐藏或退出。
- 托盘图标恢复悬浮条；隐藏后继续接收行情。普通窗口最大化时保持置顶，横条不抢键盘焦点。
- 横条所在显示器的最上层正常应用全屏时自动隐藏，退出后恢复；普通最大化不触发。手动隐藏优先，全屏期间点击恢复会等待退出全屏。原生检测约每 400ms 一次。
- 自选、位置、外观和连接参数自动保存。开机自启默认关闭，可在外观设置中启用。
- 设置页中拖动自选证券左侧手柄即可排序，插入线提示松开位置，松开后自动保存并同步到悬浮条和全部行情页；取消拖动保留原顺序。排序无需连接 OpenD。
- 密钥默认只在当前进程保存；勾选“使用 Windows 系统保护记住密钥”后加密保存，重启可自动连接。取消勾选并应用可移除持久保存的密钥，当前会话仍可连接。

设置保存在 Electron 用户数据目录的 stock-bar-settings.json。密钥不返回给页面、不写入明文文件或仓库；报价不保存为跨启动缓存。每次启动先显示 `—`，收到行情后再显示价格。

## 行情行为

基础报价持续订阅全部自选，翻页不重新连接。美股盘前、盘后及夜盘另订阅逐笔，用源时间和实际时段确认报价；OpenD 的夜盘订阅与 ETH 订阅按时段切换。缺少新时段有效数据时保留旧行情，缺少可核验涨跌基准时显示 `—`。扩展时段可能额外占用逐笔订阅额度。

BMP 权限无法订阅时尝试快照，标识快照且不猜测时延。断线保留本次运行行情，自动重连并恢复订阅。原币的具体币种和实时/延迟属性尚待独立核验；界面不再展示“时延?”或“时延属性待核验”提示，已确认的延迟行情仍标注“延迟”。

真实盘前盘后、物理多屏及独占全屏游戏仍待环境验证，详见验证记录。

## 检查与原有最小验证

```powershell
npm test
npm run build
# 先通过右键或托盘退出当前悬浮条；检查会短暂显示一个窗口。
npm run test:ui
npm run test:layout
npm run test:panel
npm run test:shortcuts
npm run test:search
npm run test:fullscreen
npm run test:recovery
# 只中断本应用的真实 OpenD 连接，并注入电源事件；不让整机睡眠。
powershell.exe -NoProfile -File scripts/check-recovery.ps1 -Live
npm run package:win
# 保留原有最小接入自动验证（密钥可通过进程环境 OPEND_WS_KEY 提供）。
npm run probe
```

常规测试包含目录匹配、离线重载、独立市场刷新及失败保留，以及固定行情样本、真实 SDK 经本地协议夹具的持续订阅/重连、临时订阅失败重试、递增退避、休眠事件、心跳超时、设置持久化、旧配置迁移和全屏可见性状态。原生搜索检查通过正式 preload/IPC/React 验证连接按钮、搜索、键盘/选字、一次点击添加、无权限、断线、目录失败及上限；原生布局检查验证三只分页、固定宽度、全部行情更新和 IPC 权限。原生恢复检查测量收到至绘制机会延迟，全屏检查验证普通最大化、全屏视频及手动隐藏。夹具不是实际市场行情，电源事件注入也不能代替整机实际睡眠验收。

Windows 构建时使用系统 .NET Framework C# 编译器生成 x64 全屏检测器；发布包已包含编译产物，用户无需编译器。打包脚本只包含编译产物及锁定的生产依赖，不包含用户配置、密钥或开发诊断。ZIP 的 SHA-256 位于同名 .sha256 文件。

开发诊断参数 --record-live 可写本地 artifacts/stock-bar-live.json 和截图；普通启动不记录行情。参数 --capture 可让已有实例导出一次当前证据。诊断文件不包含密钥，也不作为启动缓存。

### 市场快速切换

自选行情面板提供「全部 / 港股 / 美股」切换，悬浮条同步显示当前市场中已勾选的证券，并回到第一页。悬浮条不增加控件，滚轮继续翻页；设置里的总自选列表保留原排序和展示勾选。市场选择在重启后恢复，「全部」也包含 A 股。

默认 `Ctrl+Alt+M` 按全部 → 港股 → 美股循环，可在快捷键设置中修改或禁用。全屏或手动隐藏时不切换。旧配置若已将该组合用于其他操作，会保留旧绑定并禁用新增快捷键，供用户自行设定。

悬浮条可按住行情或空白区域直接拖动；右键选择「设置与自选」进入设置。右侧仅保留页码和展开/收起行情面板按钮。

悬浮条不再显示连接状态灯或文字，也不预留左侧状态区；连接状态可在自选行情面板及设置中查看。

设置中的自选列表可按「全部 / 港股 / 美股」筛选，筛选不改变悬浮条当前市场。每行的「移到最前」将该证券移到当前分组第一位；分组内拖动排序、展示勾选和移除都会自动保存，其他市场证券保留原有顺序。
