## 发现的问题及处理

1. **无密钥握手失败时，SDK 先读取空 s2c.connID，产生无帮助的 TypeError。** 适配器保留 SDK，额外读取握手的安全状态字段，向用户明确展示拒绝状态；错误文字会脱敏，不输出原始密钥或其 MD5。
2. **SDK 有 GetUserInfo 命令和协议定义，但没有便捷方法。** 在版本边界内通过 SDK 的 _sendCmd 发送限定的 1005 协议，请求 flag=6，仅取 API/行情权限；进入报告时再按白名单筛选，不包含昵称、用户 ID 或 webKey。
3. **SDK 的 stop() 只注销推送回调。** 适配器完成或取消时额外关闭本连接、清理定时器及回调，阻止完成后继续重连；不调用交易接口或全局取消订阅。
4. **交互窗口被按 Hidden 方式启动。** React 渲染成功时原生 isVisible 仍为 false，之前仅检查 IPC 的冒烟测试遗漏了此问题。采用正常交互窗口启动并等待首次绘制；同一检查结果从 visible=false、退出码 1 变为 visible=true、退出码 0。正式启动脚本固化正常窗口方式，UI 检查覆盖原生可见状态。

以上处理均在本项目适配器和启动脚本内完成，没有修改 node_modules 中的 SDK 源码，也没有修改 OpenD 配置或关闭 OpenD。
