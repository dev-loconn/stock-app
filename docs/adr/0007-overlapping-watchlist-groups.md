# 自选分组允许交叉归属，成员关系不复制证券

此为 0.10.0–0.10.1 的历史决定。用户认为分组不实用，0.11.0 起按 [ADR 0008](./0008-return-to-single-watchlist.md) 恢复单一自选列表。

分组用于切换悬浮条的关注场景，采用用户手动维护的单层结构，同一证券可以同时属于“港股”和“长期关注”等多个分组。选择交叉归属而非互斥分类，是为了避免用户在不同关注场景之间被迫二选一；自选分组表达成员关系，总自选列表继续表达证券是否被关注，同一证券加入多个组不产生独立副本。

各分组独立维护成员的展示勾选和排列顺序，以允许同一证券在不同关注场景中拥有不同的展示优先级；因此不能继续用证券上的单一全局勾选和总列表顺序代表所有组的展示选择。全部自选保留为不可删除的总清单入口；面板跟随当前视图展示全部成员，悬浮条仅展示其中勾选的成员。

总清单及自定义组均独立保存展示选择和顺序，旧配置迁入总清单。移出分组只取消该组归属；移除自选才终止全局关注并取消所有组归属；删除分组保留证券。三个窗口共用一个当前视图，全部自选继续统一更新行情，使切组不会改变证券身份或行情连接。

此关系及完整交互边界已在 2026-11-01 四轮访谈 Q1–Q19 获用户确认，随后获用户授权并在 0.10.0 实现；目标行为、实现约束和验收标准见[自选分组设计](../watchlist-groups-design.md)，已验范围见[验证记录](../watchlist-groups-validation.md)。
