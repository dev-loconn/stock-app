# 默认快捷键修订（0.9.1）

2026-11-01，用户要求将三个冲突默认键换成本机可用的组合，并指出增加第三个修饰键的组合过长。保留 Ctrl+Alt+H，面板改用 Ctrl+Alt+Q，上一页为 Ctrl+Alt+J，下一页为 Ctrl+Alt+K。

## 注册实测

通过项目的 Windows 原生管理器同时调用系统注册，Q/J/K 三组均成功，无失败项，随即释放临时注册。证据：`artifacts/shortcuts/defaults-probe-0.9.1.jsonl`。候选 Ctrl+Alt+M 返回 Windows 1409，未选为默认。

## 升级行为

旧配置中仍等于 0.9.0 默认值的 W/Left/Right 项在首次升级时替换为新默认；自定义和禁用项保留。新组合已经用于另一自定义操作时，保留对应旧项以避免重复。配置记录一次性迁移标记；升级后用户明确重新选用旧组合时，下一次启动不再自动替换。

旧自选、位置、外观及受保护密钥保留。只读诊断加载不写回配置。其余快捷键行为沿用[0.9.0 验证](./global-shortcuts-validation.md)与[设计](./global-shortcuts-design.md)。
