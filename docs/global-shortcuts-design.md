# 全局快捷键设计

状态：2026-11-01 三轮访谈及包含排除 F12 修正的完整方案已获用户最终确认。0.9.0 实现；证据与待验范围见[验证记录](./global-shortcuts-validation.md)。

## 已确认范围（2026-11-01，第一轮）

- 首版包含四个操作：显示／隐藏行情悬浮条、展开／收起自选行情面板、上一页、下一页。
- 提供默认快捷键，允许用户在设置中修改组合键、单独禁用某项操作，重启后保留配置。
- 默认组合键及具体交互边界按以下后续轮次记录。

## 已确认交互（第二轮）

| 操作 | 默认组合键 |
| --- | --- |
| 显示／隐藏行情悬浮条 | Ctrl+Alt+H |
| 展开／收起自选行情面板 | Ctrl+Alt+Q |
| 上一页 | Ctrl+Alt+J |
| 下一页 | Ctrl+Alt+K |

2026-11-01，用户后续要求替换本机冲突默认键，并指出加 Shift 的组合过长，因此 0.9.1 改用上述实测可注册的双修饰键组合；0.9.0 的 W/Left/Right 仅作为历史默认值参与一次性迁移。自定义和禁用项保留；若目标组合已用于另一自定义操作，则不替换对应旧项。迁移后明确重新选择旧组合的用户不在下次启动时再次被改键。验证见[0.9.1 记录](./default-shortcuts-0.9.1-validation.md)。

- 默认启用以上绑定；组合键被占用时允许改键。
- 通过快捷键恢复横条或展开面板时，键盘焦点留在当前应用。
- 横条因全屏自动隐藏时，四项快捷键操作均不执行，且不修改退出全屏后的显示状态。
- 非全屏且横条被手动隐藏时，面板快捷键恢复横条并展开面板；翻页快捷键不执行，也不恢复显示。
- 快捷键翻页首尾循环；不足两页时不操作。
- 设置中点击输入框后直接按组合键录入，点击保存后生效；提供取消修改、单项禁用和恢复默认。
- 新组合注册失败时保留原绑定并提示。启动时已保存组合被占用，仅该项不可用，在设置中标明失败状态，不自动更换组合键。

## 录入与失败处理（第三轮及最终确认）

- 自定义组合必须包含 Ctrl、Alt、Shift 中至少两个不同的修饰键，主键支持字母、数字、方向键和 F1–F11；首版不支持 Win 组合及单键。访谈原确认范围为 F1–F12，最终确认已根据 Microsoft 的调试器保留约束排除 F12。
- 录入期间暂停本应用四项快捷键。按 Esc 或切换到其他窗口取消本次录入，并恢复原绑定；取消录入不等于取消此前其他尚未保存的修改。
- 四项快捷键作为一组保存。重复组合、组合被占用或配置写入失败，均使整次修改不生效，保留原配置和原绑定；禁用和恢复默认也先修改草稿，点击保存才生效。
- 四项操作均按一次执行一次，按住主键不重复执行。主键松开再按才再次执行，修饰键可以持续按住。
- 面板仅在自己获得焦点时响应 Esc，不注册全局 Esc；通过快捷键展开的面板主要使用同一快捷键收起。
- 启动注册失败的项目在设置中提供“重新尝试”。用户释放冲突后手动重试，不在后台持续尝试注册，不自动分配替代组合。

## 设置与运行状态

- 设置中提供四项操作、组合键录入、单项禁用、保存、取消修改、恢复默认及注册失败项的重新尝试入口。
- 默认启用四项操作；已保存的组合和禁用选择跨启动保留。旧配置首次升级补入默认快捷键，保留原有自选、位置、外观和连接配置。
- 区分用户保存的组合与当次运行的生效状态。某项已配置但注册失败时，展示其保存组合及失败说明；不将失败状态当作用户禁用，也不将临时注册状态作为用户配置保存。
- 任意两个启用的操作不能使用相同的组合；组合比较应统一修饰键顺序、大小写及方向键表示。改键时支持两项操作交换原有组合，不能把本应用自己持有的组合误判为其他程序占用。
- 行情连接状态不决定快捷键是否可用。操作针对现有窗口和分页，未连接行情时仍遵守相同的显示、隐藏和翻页规则。
- 应用运行并完成初始化后注册快捷键；退出时释放注册。测试和诊断不应意外占用正常实例的快捷键。

配置与运行状态分离及整组保存的原因见 [ADR 0005](./adr/0005-shortcut-config-and-runtime-state.md)。

## 现有行为约束（代码核查）

- 行情悬浮条恢复显示时不获取键盘焦点；现有面板展开会获取焦点。
- 手动隐藏与全屏自动隐藏分别记录；全屏期间请求恢复横条，会等待退出全屏后显示。
- 隐藏横条同时收起面板；全屏期间现有面板入口拒绝展开。
- 现有滚轮翻页首尾循环，不足两页时不翻页。

以上为功能实现前的现状。快捷键的目标行为按已确认交互执行，其中面板通过快捷键展开时需要改变现有获取焦点的行为。

## 实现前的工程约束

- 默认组合属于 Electron 支持的 accelerator 格式；格式有效不代表组合没有被其他应用占用。
- Electron 的全局快捷键回调本身不提供按键释放或自动重复标记，不能把固定时间节流当作“长按只执行一次”的实现证据。独立 Windows 原生热键辅助进程使用 RegisterHotKey 与 MOD_NOREPEAT；每个组合只由一个注册所有者管理，不由 Electron 对相同组合重复注册。需在 Windows 实际验证按下、持续按住、松开与再次按下的完整行为。
- 原生注册按唯一组合管理，动作映射独立更新。整组改键先保留旧注册并暂存新增注册，全部准备成功且配置写入成功后提交映射，再释放不再使用的旧组合；失败时仅释放新增项。此为应用层提交协议，不能宣称磁盘与 Windows 注册存在系统级原子事务；辅助进程异常退出需反映真实不可用状态。
- 录入模式暂停动作执行并保留已有注册，仅在设置窗口处于前台且正在录入时临时使用键盘钩子，以录入并拦截已被本应用或其他应用注册的组合。录入结束后等待当次主键释放，避免仍按住的组合立刻执行操作；随后移除钩子。普通运行仅使用系统热键注册。输入仅作为组合键候选处理，不写入按键日志。
- 横条显示继续经过现有可见性控制；快捷键不能绕过全屏优先级。面板通过快捷键展开需要支持不获取焦点的路径。
- 主进程目前没有翻页入口，需要为横条提供受控的翻页命令，并复用现有分页计算。
- 更改设置需同时覆盖配置加载、旧配置兼容、输入校验、注册状态和写入失败回退，不能仅向配置文件追加字段。
- 此原生注册取舍见 [ADR 0006](./adr/0006-native-no-repeat-shortcuts.md)。
- 参考：[Electron globalShortcut](https://www.electronjs.org/docs/latest/api/global-shortcut)、[Electron 键盘快捷键](https://www.electronjs.org/docs/latest/tutorial/keyboard-shortcuts)、[Microsoft RegisterHotKey（包含 MOD_NOREPEAT 与 F12 约束）](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-registerhotkey)。

## 验收场景

| 场景 | 预期结果 |
| --- | --- |
| 在其他普通应用中触发四项默认组合 | 对应操作生效；显示横条及快捷键展开面板均不改变当前应用焦点 |
| 长按任一组合，再松开主键并重按 | 长按期间只执行一次，重按再执行一次；持续按住修饰键不妨碍重按 |
| 从末页向后、首页向前翻页 | 分别回到首页和末页；不足两页时保持原页 |
| 手动隐藏后按翻页组合 | 保持隐藏，不改变页码 |
| 手动隐藏后按面板组合 | 恢复横条并展开面板；再次按面板组合收起 |
| 面板展开时隐藏横条 | 横条隐藏，面板同步收起 |
| 进入全屏后分别触发四项组合 | 四项均不执行；退出全屏后保留触发前的显示意图和页码 |
| 录入快捷键时按原组合 | 不触发横条、面板或翻页操作 |
| 录入期间按 Esc 或切换到其他窗口 | 取消本次录入，恢复原绑定 |
| 在其他应用中按 Esc | 不因本应用面板已展开而被全局拦截 |
| 设置不受支持的组合、包含 F12 的组合或重复组合 | 显示具体错误，原绑定及保存配置保持有效 |
| 交换两项操作的原组合并保存 | 整组生效，不把本应用持有的组合误报为外部占用 |
| 一项新组合被其他进程占用，或配置写入失败 | 整次修改失败，原配置和原绑定保留 |
| 禁用一项、取消修改、恢复默认 | 未保存前运行绑定不变；保存成功后整组更新 |
| 重启及旧配置首次升级 | 保存选择正确恢复，旧配置补入默认快捷键且其他用户配置保留 |
| 启动时一项组合被其他进程占用 | 其他可用项正常注册，失败项展示原因，无自动替代或后台持续重试 |
| 释放冲突后点击重新尝试 | 失败项按已保存组合重新注册，状态更新 |
| 断开行情连接后使用快捷键 | 窗口与分页仍遵守相同规则 |
| 退出应用后由其他进程注册原组合 | 组合已释放 |

验证结合状态/配置测试与原生窗口检查；焦点、真实占用和长按行为需要 Windows 实际证据，范围见验证记录。
