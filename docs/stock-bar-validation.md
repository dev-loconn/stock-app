# 首个真实行情悬浮条版本

本页记录首个开发版本及当时的待办。后续 0.2.0 已实现全屏隐藏和 ZIP 交付，当前结果见 [全屏与发布验证](./fullscreen-release-validation.md)。

2026-10-23，Asia/Shanghai。已在开发构建中实现并实际启动真实行情悬浮条，完整 ZIP 产品尚未交付。

## 已完成

- Electron 主进程持续管理 OpenD 连接、全部自选订阅、行情心跳和市场状态。
- 窄横条显示简称、价格和涨跌幅，红涨绿跌、平盘灰色，默认约 900 × 44 逻辑像素。
- 常规报价以昨收计算涨跌；美股盘前/盘后使用带源时间的逐笔确认时段，盘后使用同日常规收盘基准。缺少基准则涨跌幅未知，缺少新时段有效报价则保留旧行情。
- 对盘前盘后额外请求 ETH 逐笔，单只证券可能占用基础报价和逐笔两种订阅额度；常规时段仅需基础报价。
- 拒绝无效或更旧的基础报价，区分源时间和接收时间，按源市场时区解释字符串时间，支持纽约冬夏令时及提前收盘。
- BMP 权限无法订阅时尝试快照回退，并标为快照/时延未知；不把行情等级或连接成功当成实时性证据。
- 断线保留本次运行行情，以逐步延长的间隔重连并恢复订阅；独立处理证券权限和行情错误。
- 滚轮手动分页，每页最多 5 只，窄屏或大字号时减少数量；悬停详情使用独立窗口，避免被窄横条裁切。
- 可拖动空白手柄、右键菜单、托盘隐藏恢复、单实例；横条不可抢焦点，设置窗口可正常输入。
- 自选代码核验、确认添加、删除、排序，最多 10 只；自选、外观、窗口位置和连接设置保存。
- Windows 系统保护保存密钥可选，页面不回读密钥。自选和设置可跨启动恢复，报价不从磁盘恢复。
- 可调整宽度、字号、透明度，提供默认关闭的开机自启选项；多屏位置有可见区域回退，仍需多屏实测。

用户选择使用 Windows 系统保护记住密钥后，已重启最终构建核验：

- 自选 4 只及密钥自动恢复，无需再次输入。

- 原生窗口 visible=true、focusable=false、alwaysOnTop=true。默认 CSS 宽度 900；原生尺寸会受 Windows 缩放取整影响。

原始本地证据为 artifacts/stock-bar-live.json、artifacts/stock-bar-live.png、artifacts/stock-bar-ui.json 和 artifacts/stock-bar-before-restart.json。record-live 是诊断启动选项，普通启动不写行情快照；证据不加载为下一次启动缓存，也不包含密钥。

2026-10-24 00:04（Asia/Shanghai）最终复核：普通模式启动后自动连接，保留用户最新调整的 3 只自选及 700 宽度；一次性导出时苹果已收到 54 次推送、SPY 60 次。原生 UI 检查仍通过，启动未连接时 3 只价格均为 `—`。已关闭持续诊断记录，当前实例正常运行。live 文件为这次单次导出的证据，原四样本验证及重启前记录保留在历史证据中。
