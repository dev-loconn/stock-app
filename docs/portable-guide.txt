股票行情悬浮条 0.11.4 · Windows 11 x64 便携版

1. 将 ZIP 完整解压到有写入权限的普通目录，再双击 stock-bar.exe。
   请勿只从 ZIP 内双击某个 EXE。无需安装 Node.js、npm 或 .NET SDK。
   Electron、独立 Python/AKShare 运行时及行情依赖均随包提供，无需另装 Python。
   原生全屏检测器和快捷键管理器使用 Windows 11 自带的 .NET Framework。

2. 默认使用富途云端，无需安装 OpenD。打开设置，点击“登录富途”，
   在系统浏览器的富途官方页面登录，仅授权行情读取，完成后自动连接行情。
   刷新凭证由 Windows 系统保护加密保存，下次启动自动连接；保护不可用时仅本次运行有效。
   “退出云端登录”清除本机保存的凭证；富途端的授权撤销请使用官方管理页面。
   云端仍受账号行情权限、地区、额度与网络环境限制。
   证券名称目录由独立 AKShare 环境同步，不依赖富途登录；首次同步可能需要数分钟。
   已有目录可离线搜索，没有目录时仍可输入完整代码核验添加。

   本地备用：在“连接方式”选择“本地 OpenD（备用）”，单独启动并登录 OpenD。
   原有本地端口和密钥保留；默认 127.0.0.1:33333，必须匹配自己的 OpenD 配置。
   11111 通常为 TCP API 端口，不用于此 WebSocket 连接。
   SSL 与 WebSocket 密钥也需匹配 OpenD；密钥只在本地密码框填写。
   点击“应用并连接”，等待证券目录加载，再输入名称、代码片段或拼音首字母搜索。
   例如 腾讯、Tencent、700、tx；支持港股/美股筛选，结果旁点击“添加”会核验并保存。
   方向键选择后可回车添加，中文输入法选字不触发添加；自选不设固定总数上限，不重复添加。
   目录未收录时，可输入完整代码（如 HK.00700、US.AAPL）“核验并添加”。
   名称和别名覆盖因证券而异，不保证每只证券都有双语名称及所有俗称。

3. 空白手柄拖动，滚轮手动翻页，齿轮打开设置。右键和托盘均可隐藏、恢复或退出。
   美股杠杆／反向 ETF 在悬浮条优先显示纯代码（如 SOXL、SOXS、TQQQ），按名称特征和代码名单识别，未识别时保留名称。
   面板和设置仍保留证券名称。悬浮条及面板的价格固定显示两位小数，涨跌幅计算继续使用原始报价精度。
   外观设置的“悬浮条每页最多显示”默认 3，可设为正整数；超出一页继续滚轮翻页，屏幕不足时自动减少实际每页数量。
   单只证券宽度默认 180 逻辑像素，接受正整数，已取消 140～360 范围限制；窗口仍适配屏幕工作区。
   在自选管理逐行勾选“显示在悬浮条”，修改即时保存；顺序跟随自选拖拽排序。新增默认不勾选，旧配置已有自选保留展示，重启记住选择。
   自选不设应用内固定总数上限，管理列表内部滚动。未勾选项仍在全部自选行情面板更新；服务数量或额度受限时显示异常，保留自选和展示选择。
   调整字号不改变证券宽度，末页不足时留空。正常连接仅显示小圆点，异常在左侧提示一次。
   点击右侧箭头在横条下方展开全部自选行情面板，最多 6 行，其余内部滚动；空间不足时向上展开或缩小。
   再次点击箭头或在面板获得焦点时按 Esc 收起；点击外部和鼠标移出保持展开。
   右键、托盘、设置的“查看行情”打开同一面板。
   面板显示名称、代码、价格、涨跌幅和状态；不弹出行情悬浮详情。“管理自选”收起面板并打开设置。
   拖动横条时面板跟随；隐藏或进入全屏时一起收起，恢复横条及重启后保持收起。
   手动隐藏后查看全部行情会恢复横条并展开；全屏自动隐藏期间仅提示退出全屏后再查看，不排队弹出。
   同一显示器最上层正常应用全屏时自动隐藏，退出全屏后恢复；普通最大化不触发。
   手动隐藏优先。全屏期间点击恢复，仍等退出全屏再显示。
   不同显示器独立判断，检测约每 400ms 一次；检测器异常时恢复正常可见并自动重试。
   隐藏只影响横条，行情连接继续。退出只关闭本程序，不关闭 OpenD。

4. 自选、顺序、外观、位置和连接设置保存在当前 Windows 用户的
   %APPDATA%\stock-bar\stock-bar-settings.json，不在程序目录中。
   密钥默认只保留当前会话；可勾选使用 Windows 系统保护记住密钥。
   跨版本更新：从托盘退出旧版本，将新 ZIP 解压到新目录并运行，自选和设置自动保留。
   0.11.0 已移除分组；从 0.10.x 更新时保留总清单全部证券，沿用“全部自选”的排序和展示勾选。
   迁移前原配置备份为同目录 stock-bar-settings.json.v4-backup；已有不同备份时另存带时间后缀的副本。
   旧版总宽设置自动迁移为单只证券宽度 180；其他设置和受保护的密钥继续保留。
   不要把用户配置或密钥复制到分发 ZIP。报价不跨启动缓存，启动后重新获取。
   AKShare 证券搜索目录保存在用户数据目录的 security-directory-akshare.json；有目录后可断线搜索，添加证券仍需连接。
   目录超过一天时联网后台刷新，也可点“刷新目录”；按市场独立更新，失败保留已有目录并显示状态。
   若启用了开机自启，程序换目录后请在新版本设置中重新应用自启选项。

   全局快捷键（0.9.1 默认）：Ctrl+Alt+H 显示/隐藏横条，Ctrl+Alt+Q 展开/收起面板，
   Ctrl+Alt+J/K 前后翻页。默认启用；若被其他软件占用，设置会标明失败，其他可用项继续生效。
   升级时把 0.9.0 的旧默认 W/左右键替换为新组合，保留自定义和禁用项；若新组合已用于其他自定义操作，则保留对应旧项避免重复。
   在设置页“全局快捷键”点击组合录入，可改键、单项禁用、恢复默认和取消修改；四项一起保存后生效。
   支持 Ctrl、Alt、Shift 中至少两个搭配字母、数字、方向键或 F1-F11；不支持 Win、单键和 F12。
   录入时不执行快捷键操作，Esc 或切换窗口取消录入。冲突或保存失败保留原配置；可手动“重新尝试”。
   快捷键恢复横条或展开面板不抢焦点，长按只执行一次，翻页首尾循环。
   全屏自动隐藏期间不执行四项操作；手动隐藏后面板键恢复并展开，翻页键保持隐藏。
   面板 Esc 收起仅在面板获得焦点时有效；在其他软件中可再按面板快捷键收起。

5. 常规/盘前涨跌相对上一交易日常规收盘；盘后相对同日常规收盘。
   美股夜盘相对该轮夜盘开始前最近的常规收盘，跨美东午夜不更换基准。
   缺少可靠基准时涨跌幅为 —，缺少新时段行情时保留旧价并标明等待。
   仅在源服务明确确认时显示“延迟”；未显示该标签不代表已经核验为实时。
   夜盘单独显示“夜盘”状态；没有权限或证券不支持时保留旧价并提示异常或等待。
   扩展时段逐笔额外占用订阅额度；不包含交易下单。

验证范围及待验项目见 docs。当前没有代码签名或自动更新。
搜索验证与当前真实 OpenD 接入状态见 docs/security-search-validation.md。
AKShare 目录同步说明（0.6.10 起内置完整运行环境）：
港股、美股和沪深京 A 股代码名称库可每日自动同步；目录搜索不需要富途登录，添加和报价需要富途授权及相应行情权限。
直接运行即可，不需要执行安装脚本。请完整保留 resources\app\runtime\python 目录。
高级用法可将 STOCK_BAR_PYTHON 指向自备的 AKShare 1.19.3 解释器；默认优先使用包内隔离环境。
Python 仅负责目录同步，不影响现有自选行情显示。
启动后首次同步可能需要数分钟，可在设置页查看各市场条数、更新时间和错误。失败保留旧名单，已有名单可离线搜索。
