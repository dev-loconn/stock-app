# 云端默认连接与 OpenD 备用：桌面集成验证

版本 0.5.0，实施日期 2026-10-24（Asia/Shanghai）。

默认连接改为富途云端。设置页“登录富途”通过系统浏览器打开官方 OAuth 页面，使用 Public Client + S256 PKCE、随机 state、仅行情读取 scope；回调仅绑定 127.0.0.1。登录超时或取消释放回调服务，错误不暴露凭证或账户标识。访问令牌仅驻留主进程；刷新令牌使用 Windows safeStorage 加密存储。系统保护不可用时只维持当前会话；加密文件无法读取或刷新授权失效时需要重新登录。

启动自动刷新保存的授权，连接云端 WebSocket；订阅自选并通过批量 REST 补齐报价、市场状态和源时间。每 4 分钟更新令牌并发送 refresh，等待鉴权层确认，失败则重连恢复订阅。无订阅确认但已收到 QUOTE 时仍处理数据，不因确认缺失而误判失败。价格与行情时间不会写入跨启动缓存。

本地 OpenD 是手动选择的备用模式。原端口、SSL 和密钥保留；自选、目录、外观及位置共用。切换停止旧订阅和连接，并创建新的行情状态，避免旧来源报价混入新来源。退出云端清除本机授权和云端报价，但不修改官方账户或本地 OpenD 登录。

正式桌面应用默认云端，原有 6 只自选、外观和本地证券目录成功保留。用户从正式设置页完成官方授权后，实际显示“已连接富途云端”和“Windows 系统保护已保存登录”；6 只自选均收到云端 QUOTE：HK.01810、HK.09903、US.SOXL、US.AAPL、US.SPY、HK.00700。北京时间 23:50 的诊断快照包含 6 条有效报价及各自源时间，推送计数均大于 0；证据为 `artifacts/stock-bar-live.json` 和同名 PNG。仅检查授权文件字段，确认存在 encryptedRefresh、没有明文 token 字段，未输出凭证内容。

当前为周末，报价源时间是上一交易日，不据此声称连续实时变化通过。部分扩展行情字段的更新时间已落在对应交易时段边界之外，保守保留常规报价；跨时段源时间语义仍需实盘核验。前一轮独立脚本结果见 [cloud-api-validation.md](./cloud-api-validation.md)。

## 限制

- 云端静态信息接口只核验已知代码；本轮尚未核实全市场目录下载接口。保留已有本地目录搜索，新用户使用完整代码添加。云端模式禁用全量目录刷新，备用模式继续支持。
- 0.7.2 已接入云端带源时间的盘前/盘后逐笔；0.8.0 增加 `OVERNIGHT` 夜盘补拉及推送。按 `BEFORE` / `AFTER` / `OVERNIGHT` 取得对应时段数据，在交易期间订阅 `TICKER`。不直接采用没有独立时间戳的 QUOTE 扩展价格；休市启动补回对应结束时段。SOXL 的真实响应和验证范围见 [盘前盘后修复](./us-session-validation.md)、[夜盘验证](./overnight-validation.md)。
- 周末静态报价不能证明开市持续实时更新、时延属性或跨盘前/盘后正确性。账户地区、市场权限和额度仍由富途决定。
- 官方长连接 auth/heartbeat 文档存在描述差异。实现采用 auth 页的周期 refresh，仍需真实超过 10 分钟连接及恢复实测。
- 本机退出登录只清除本机凭证；富途端的授权撤销由官方管理页面处理。

复现原生云端专项：设置 STOCK_BAR_CLOUD_CHECK=1 后运行 `vitest run tests/desktop-cloud.test.ts`。专项强制使用明确的 --cloud-check、隔离配置与 127.0.0.1 夹具；正常运行不会读取夹具地址。
