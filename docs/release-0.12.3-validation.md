# 0.12.3 发布验证

## 功能

- 行情面板全部/港股/美股筛选，同步悬浮条并持久保存选择；Ctrl+Alt+M 可自定义或禁用。
- 设置自选列表独立市场筛选，分组内移到最前、拖动排序、展示勾选和移除；保留其他市场。
- 悬浮条支持行情/空白区域拖动，去掉拖动图标、设置按钮和连接状态区；右键进入设置。
- 面板顶部合为一行：市场切换、连接状态、管理自选；无自选数量，宽度随悬浮条内容对齐。
- 修复非整数 Windows DPI 下连续拖动导致尺寸累积增长，并补偿面板宽度取整。
- 包含远端 c1b3270 的 OpenD 乱序逐笔保护修复。
