# 0.6.7 恢复真正的圆角缺口

2026-10-25，用户指出 0.6.6 虽消除了白块，圆角外观却丢失。新的桌面像素断言确认：旧版四角缺口仍被深色窗口表面填充，仅检查“无白色”不足以证明圆角正确。

## 当前实现

移除不透明窗口的 setShape 拼接及对应几何函数，恢复透明窗口与现有 CSS 8px 圆角。保留本应用原生深色主题。

为避免重复显示透明窗口时的闪烁，面板原生表面首次准备后持续保留，打开/收起使用不透明度切换。收起时透明度为 0，同时忽略鼠标、禁止获取键盘焦点，文档设为 inert；展开时恢复交互和完整不透明度。首次表面显示在 0 不透明度下预热 250ms，随后打开不重复执行原生 show/hide。准备期间收起会取消延后显示。

按钮切换、面板获得焦点时 Esc 收起、外部失焦保持展开、隐藏/全屏生命周期均保留。初始状态及重启仍收起，未保存面板展开状态。

## 桌面像素验证

在高对比诊断背景上检查完整面板截图，四角既不能出现近白像素，2 DIP 方形切口还必须实际透出背景，原始页面截图四角 alpha 应接近 0。0.6.6 在背景透出断言上失败，证明旧测试捕获不到圆角被填充的问题。

开发版 `artifacts/panel-round-opacity/` 的四角均为零近白像素，切口背景透出比例均为 1；8 次连续展开均为零中断。新增每次收起后的桌面像素检查，确认面板确实不可见；原生回归还检查收起后无键盘焦点、内容 inert 以及准备期间取消不会稍后自动出现。

最终便携版证据位于 `artifacts/panel-rounded-packaged/`。多屏和其他缩放、显卡组合的边界仍需实机验证。测试仅保存面板矩形范围的裁图，不保存周围桌面。

0.6.7 最终结果：构建及 58 项常规回归通过（5 项原生诊断默认跳过）；正式 EXE 的 107 项原生断言通过。四角各 361 个检测像素中近白像素均为 0，四个切口背景透出比例均为 1，8 次展开无闪帧；每次收起后画面检测确认面板不再显示。已查看完整桌面裁图，圆角轮廓恢复。
