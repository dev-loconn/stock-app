# 0.6.0 自选行情面板实现与验证

0.6.4 行为更新：点击外部和切换窗口不再收起列表；专用箭头切换开关，面板获得焦点时 Esc 收起。隐藏横条、全屏隐藏、退出和管理入口仍按既有生命周期收起。下文失焦自动收起及拖动后恢复焦点的描述属于历史实现。

当前行为更新：0.6.3 按用户要求移除了横条及面板行的行情悬浮详情框。下文为 0.6.0 的历史验证记录，其中提示窗相关行为已被取代；现行检查在鼠标停留后断言没有新增详情窗口。0.6.2 恢复的圆角与 0.6.1 原生边框修正继续保留。

2026-10-25，用户逐轮确认 Q1–Q12，并最终授权实施。独立的全部自选行情窗口已替换为依附行情悬浮条的只读面板。

## 已实现

- 右侧箭头切换展开/收起，右键、托盘及设置入口复用同一面板；管理及空列表添加入口进入原有设置。
- 深色、不透明、字号随设置变化的紧凑列表，保留名称、代码、价格、涨跌幅及状态标签；最多 6 行，其余滚动。默认同横条宽度，最小 320 逻辑像素，工作区不足时缩小。
- 下方优先、空间不足向上、左右边缘平移，拖动横条时跟随；收起及行情更新不创建新订阅。
- 用户主动展开可获得焦点，Esc、外部点击、箭头及管理入口收起；鼠标移出保持展开。行详情复用原有报价时段、数据时间和基准，面板展开时暂停横条提示。
- 手动隐藏、全屏隐藏时收起，恢复及重启默认收起。手动隐藏时明确查看可恢复；全屏隐藏期间提示等待退出，不排队自动弹出。

`WatchlistPanel` 管理瞬时窗口状态；行情继续来自 `MarketService`，偏好及自选持久化方式沿用现有实现。窗口位置计算使用 Electron DIP，包含负坐标显示器和工作区限制。缓存请求的尺寸，避免分数缩放下每次报价都触发原生窗口调整；首帧后单独归一化 Windows 构造窗口的尺寸。

## 当前验证证据

- 构建：`npm run build` 通过 TypeScript、Vite 和原生检测器构建检查。未改变 C# 检测器逻辑，构建脚本复用未变更的检测器，避免覆盖正在使用的同一二进制。
- 自动回归：使用捆绑 Node.js 24.19.0 执行 Vitest，56 项通过、5 项原生诊断默认跳过。新增定位样本覆盖上下翻转、左右限制、负坐标、小工作区、0/1/6/10 只及 12/14/20 字号。系统 PATH 中的 Node 20 低于项目要求，SDK WebSocket 测试不能用它作为有效结论。
- 原生面板检查：`npm run test:panel` 使用独立用户目录、本地协议夹具、正式 preload/IPC/React 及真实 Electron 窗口；36 项断言通过，结果和截图位于 `artifacts/panel-fixture/`。验证列表、六行滚动、箭头、Esc、提示窗、实时更新、断线旧价、管理、只读权限、外观、隐藏和全屏状态联动，以及正常退出。
- 原有布局及拖拽检查：Node 24 下执行 `scripts/check-layout.ps1`，28 项断言通过，验证三只分页、固定宽度、末页留空、10 只更新、列表同步、拖拽排序/取消/保存失败及 IPC 权限。结果位于 `artifacts/layout-fixture/result.json`。
- 真实鼠标检查：通过 computer-use 操作隔离测试窗口，横条拖动后面板保持展开；箭头真实点击可展开/收起。另启动独立 Electron 进程作为外部按钮，第一次点击从 0 变为 1，行情面板同时收起。证据为 `artifacts/panel-interactive-3/interactive-result.json`，其中 `firstExternalClick=true` 且 `panelOpen=false`。首次对资源管理器的自动化访问等待批准超时，未操作其内容，改用独立测试进程完成此项。

拖动时的原生失焦与普通外部失焦分别处理，使用本应用窗口的鼠标及移动事件，不安装全局输入钩子。快速重开时忽略过期的失焦事件；退出时先收起并检查窗口是否已销毁，避免清理回调访问失效窗口。
