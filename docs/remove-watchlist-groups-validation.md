# 移除自选分组验证（0.11.0）

2026-11-01，用户在使用 0.10.1 后明确要求移除分组，认为不实用。0.11.0 恢复单一自选列表，悬浮条直接按该列表的展示勾选和拖拽顺序分页，面板展示全部自选；不再预留组名按钮空间。

## 实现与配置保留

- 删除分组按钮、设置页管理和成员选择控件、分组样式、公开桥接接口、主进程分组命令与对应功能模块。旧分组诊断脚本和测试已移除，原有设计文档和 ADR 标记为历史记录，由 [ADR 0008](./adr/0008-return-to-single-watchlist.md) 替代。
- 保存配置升级为 v5；v1/v2/v3 保留原有全局展示语义，v4 使用全部自选的顺序及勾选还原完整列表，不按最后活动组过滤、不合并组内勾选、不删除仅在其他组出现的证券。保留名称、别名、位置、外观、连接参数、受保护密钥与快捷键。
- v4 首次持久迁移前，将原始文件以不覆盖方式保存为同目录 `stock-bar-settings.json.v4-backup`；已有不同副本时另存带时间后缀的新备份。备份仍是原加密配置，不解密输出凭证；诊断只读加载不创建备份或改写文件。
- 全部自选引用缺失、重复、指向未知证券或展示选择无效时，不覆盖原配置。旧组元数据已无业务作用，不因其损坏而阻止有效总清单恢复；原始元数据保留在备份中。
- 保留此前候选配置先写盘再发布的串行提交方式，以及已停止连接不因纯展示修改被主动唤醒的行为。
