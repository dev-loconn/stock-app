# 第一版验收清单

当前状态：0.2.2 补齐主机 WLAN 实际断网、真实 OpenD/FTWebSocket 进程重启、整机实际睡眠/休眠的验收，三项本机实测通过，详见 [真实系统恢复验收](./system-recovery-validation.md)。0.2.1 已修复订阅恢复、递增退避和独立心跳，33 项自动回归及原生 Electron 恢复/延迟检查通过；10 只自选的内部更新延迟开发版最长 103ms、便携版 104ms，详见 [恢复与延迟验收](./recovery-latency-validation.md)。真实盘前/盘后、源端时延属性、多屏等其余未验范围继续保留，不能据此宣称全部产品验收通过。历史记录见 [全屏与发布验证](./fullscreen-release-validation.md)、[stock-bar-validation.md](./stock-bar-validation.md) 和 [opend-validation.md](./opend-validation.md)。

下表的“部分通过”保留尚未实测的交互及环境缺口；固定样本通过不等同真实扩展时段通过。多屏及独占全屏游戏没有当前环境，不宣称已通过实测。

记录结果时使用：通过、部分通过、失败、待实盘、待环境、未执行。每项补充实际结果和证据；回放测试与真实行情验证分开记录。涉及账号、连接 key 或日志时不记录敏感值。
