# 快捷键配置与运行状态分离，改键按整组提交

用户保存的快捷键组合和禁用选择属于持久配置，注册成功或被其他程序占用属于当次运行状态；启动失败保留用户原组合并提供手动重试，避免临时冲突改变用户下一次按键的含义。四项改键按一组验证、注册并保存，任一项重复、被占用或写入失败都保留原配置及原绑定，避免部分成功导致用户无法判断当前生效的操作。

此边界选择了稳定的用户配置和明确的失败反馈，代价是需要管理配置草稿、实际注册状态及整组回退，不能逐项修改并在失败时自动分配其他组合。各项行为已在访谈 Q9、Q12、Q15 中确认，完整设计已于 2026-11-01 最终确认并在 0.9.0 实现；详细规则与验收场景见[全局快捷键设计](../global-shortcuts-design.md)。
