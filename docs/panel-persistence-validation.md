# 0.6.4 面板由按钮或 Esc 收起

2026-10-25，用户要求移除列表的外部点击自动收起行为，并补充保留 Esc 收起。

已移除 WatchlistPanel 的 blur 计时器、鼠标交互时间与拖动后的焦点恢复逻辑。点击外部或切换窗口时，面板保持展开，焦点留给目标应用。专用箭头继续切换打开/关闭；面板获得键盘焦点时按 Esc 收起，不注册全局 Esc。隐藏横条、全屏自动隐藏、管理入口和退出继续按原有窗口生命周期收起。

原生检查使用不同的真实 Electron 窗口获得焦点，等待超过旧版 120ms 自动收起延时后断言面板仍展开；同时移动横条，检查面板跟随且不抢回焦点。20 次循环分别验证外部焦点保持、面板保持展开、按钮主动关闭和重开后的深色画面。原有 Esc、圆角、无原生边框、无行情悬浮框、行情同步等检查继续执行。

开发版证据为 `artifacts/panel-persistent-development/`，便携版为 `artifacts/panel-persistent-packaged/`。物理多屏、全屏游戏及其他环境边界沿用既有验证文档；不将同进程真实窗口的失焦检查记为逐一完成了各第三方应用的鼠标实测。
