## 已通过

- `npm run build`：TypeScript、Vite 及两个 x64 原生辅助程序编译成功。
- Node 24 常规测试：14 个测试文件通过，91 项通过，6 项需显式启用的桌面检查跳过。包括原有云端/OpenD 本地协议夹具、旧配置迁移，以及新增组合规范化、重复/保留键校验、事务失败、录入暂停、快捷键重载及并发设置保存。
- `npm run test:shortcuts`：独立测试配置、原生窗口和 Windows 系统热键注册，45 项断言通过。报告为 `artifacts/shortcuts/result.json`，界面截图为 `artifacts/shortcuts/settings.png`。
- 原生检查覆盖：长按显隐和面板只执行一次、不抢另一窗口焦点、首尾循环、单页不操作、保留修饰键并重按主键、手动隐藏、全屏状态优先、面板联动、原组合及外部占用组合录入、录入后持续按住不误触、F12 拒绝、Esc/失焦取消、UI 禁用后保存、实际占用失败、键位互换、实际阻断配置临时文件写入及恢复、启动单项失败、手动重试、退出释放。

- `npm run test:panel`：既有面板原生回归通过，106 项检查，包含鼠标入口、焦点、位置、报价更新及窗口生命周期。

## 本机默认组合占用

实际注册时 `Ctrl+Alt+H` 成功；`Ctrl+Alt+W`、`Ctrl+Alt+Left`、`Ctrl+Alt+Right` 返回 Windows 1409（已注册）。应用保留约定默认值并逐项标明失败，不占用其他应用的组合，也不自动替换。操作检查使用独立的 `Ctrl+Alt+Shift+F6/F7/F8/F9`，通过正式改键路径保存；这些只是隔离测试配置，不修改正常用户设置。

## 证据口径与边界

- 全屏优先级使用既有可见性控制器注入全屏样本，检查真实窗口显示及输入动作；本次不是独占游戏、物理多屏全屏或所有全屏检测条件的重新验收。
- 按下、重复按下及释放使用 Windows `SendInput`，系统注册采用 `MOD_NOREPEAT`；未将此记录写作人工物理键盘长按验收。
- 焦点目标为独立的编辑器测试窗口；未遍历所有第三方软件、管理员提权窗口、其他键盘布局及安全桌面。
- 在受限沙箱中，Electron 启动、系统热键注册和 loopback 连接遭系统限制；上述成功结果来自正常 Windows 环境及独立测试配置。没有因此改动行情连接实现。
- 快捷键与行情连接独立，本次原生检查使用离线行情状态；不声称重新验证真实市场报价。
