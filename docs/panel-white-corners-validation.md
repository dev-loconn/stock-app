# 0.6.6 圆角白色背景修复

0.6.7 更新：仅消除白块仍使圆角缺口被深色填充，因此已增加实际背景透出检查并调整表面显隐。现行实现见 `panel-rounded-surface-validation.md`，下文保留 0.6.6 的历史证据。

2026-10-25，用户报告 0.6.5 的圆角有白色背景。之前原生检查仅判断最外角是否被裁掉，未覆盖圆弧附近的桌面像素。

## 复现和修复

扩展显式桌面采样检查，在面板后放置诊断背景，对完整面板矩形截图，并检查四角各 10 DIP 方形区域。0.6.5 四角分别检测到 15、7、11、4 个近白像素，回路报错 `White pixels appear around the native panel corners`。原始截图和计数保存在 `artifacts/panel-white-corners-before/`。

仅改变网页底色、系统圆角偏好、系统边缘颜色或区域拼接方式均未消除白角；无自定义裁切时白角消失。进一步对比发现应用自绘界面为深色，Electron 原生主题仍跟随系统浅色；设置 `nativeTheme.themeSource = 'dark'` 后四角近白像素均变为 0。

撤回所有无效的裁切、辅助程序和页面底色实验，仅保留原生深色主题设置；圆角仍使用 0.6.5 的不透明窗口和原生形状。这项修正使本应用的原生绘制及菜单也使用与界面一致的深色，不更改 Windows 系统主题。最小修复对照证据为 `artifacts/panel-white-corners-minimal-fix/`。

## 当前验证范围

显式原生诊断同时检查四角没有近白像素、8 次展开画面不中断，并继续运行圆角区域、无边框、无悬浮详情、按钮/Esc 收起、外部失焦保持展开及行情更新检查。0.6.6 便携程序证据位于 `artifacts/panel-white-corners-packaged/`。

仅保留测试面板范围的桌面裁图，不保存周围桌面。实际多屏、其他缩放以及其他 Windows 配色环境仍需实机验证；截图和当前机器上的采样不代表所有系统组合均已通过。

最终结果：0.6.6 构建和 59 项常规回归通过，5 项需显式开启的原生检查默认跳过；正式 EXE 的 105 项原生断言通过。四个角各 361 个采样像素中近白像素均为 0，8 次展开均未出现背景透出或亮帧中断。已查看实际桌面裁图，白色角块消失。
