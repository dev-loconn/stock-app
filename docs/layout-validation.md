# 0.3.0 布局与全部自选行情验证

日期：2026-10-24（Asia/Shanghai）。本次验证使用本地协议夹具，窗口为真实 Electron + React；测试数据不代表真实市场行情。

## 变更

- 连接区由 70 缩至 32 逻辑像素；正常仅显示圆点，异常全局提示一次，悬停查看详情。
- 单只证券宽度默认 180，可调 140～360；每页最多 3 只，屏幕不足时减少容量。总宽按容量计算，末页不拉伸、不移动窗口，调字号不改变单只宽度。
- 空自选保留添加入口；增删自选自动重新计算总宽。若屏幕工作区连一只证券及两端控件都无法容纳，窗口以可用工作区为限。
- 版本 1 的整条宽度迁移为版本 2 的单只宽度 180，保留自选、顺序、位置、其他外观、连接参数和系统保护密钥；迁移后保存为新版配置。
- 独立“全部自选行情”窗口展示名称、代码、最新价、涨跌幅、行情状态、带日期与时区的数据时间。按自选顺序实时更新，滚动查看全部自选；“管理自选”打开现有设置。
- 悬浮条右键、托盘菜单和设置页均提供“查看全部行情”入口。重复打开复用窗口；总览通过隔离的 preload 读取数据，不能通过 IPC 修改外观或自选。

## 复现

使用 Node.js 22.12 或更新的兼容版本，先构建：

```powershell
npm test
npm run build
npm run test:layout
# 对打包程序运行同一套检查：
powershell.exe -NoProfile -File scripts/check-layout.ps1 -Executable '新程序目录\stock-bar.exe'
```

本次新增总览和布局检查不代替真实盘前盘后行情、物理多屏或独占游戏验收。历史恢复、全屏和真实 OpenD 验收记录保留各自版本与边界。
